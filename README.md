Monthly Expense Tracker

A simple and interactive Personal Expense Tracker built with Streamlit that helps users manage their daily income and expenses. The application provides an intuitive interface to record financial transactions, monitor spending, and analyze expenses through summary metrics and visualizations.

📌 Features
🏠 User-friendly Home page
➕ Add Income transactions
💸 Add Expense transactions
📋 View complete transaction history
📊 Financial summary with:
Total Income
Total Expenses
Current Balance
📈 Category-wise expense analysis
📊 Interactive bar chart for expense visualization
📅 Record transactions with date and description
💾 Session-based transaction management using Streamlit Session State
🛠️ Technologies Used
Python
Streamlit
Pandas
Datetime

🚀 Getting Started
1. Clone the repository
git clone https://github.com/your-username/monthly-expense-tracker.git
2. Navigate to the project folder
cd monthly-expense-tracker
3. Install the required packages
pip install -r requirements.txt
4. Run the Streamlit application
streamlit run app.py

The application will open automatically in your browser.

📷 Application Workflow
Open the application.
Choose Add Transaction from the sidebar.
Record either an Income or an Expense.
View all transactions in the Transaction History page.
Analyze your financial status in the Summary page with metrics and category-wise charts.
